# 设备领用台

这是一个可独立启动的 AutoRush 测试演示程序。表单和 JSON API 共用设备领用规则，可展示页面断言和 HTTP 断言如何出现在同一份运行报告中。

## 先体验页面

在项目根目录运行以下命令。演示服务只需要 Python 标准库，监听本机回环地址。

```bash
python demo/serve.py
```

打开 <http://127.0.0.1:8766/>，选择 **USB-C 扩展坞**。先提交 **9** 件，查看「每次最多可领用 8 件」提示。改为 **2** 件再提交，页面会显示成功回执。点击 **重置**可回到初始状态。

## 在 AutoRush 中演示完整流程

1. 保持演示服务运行，并启动 AutoRush 控制台和后端。Web 执行需要 Playwright Chromium，测试目标允许访问 `127.0.0.1`。
2. 在另一个终端运行以下命令。`--headed` 会打开浏览器窗口显示测试动作，去掉该参数可以无头运行。

   ```bash
   python demo/run_flow.py --headed
   ```

3. 打开 AutoRush 的 **运行报告**，查看名称以「演示 · 设备领用流程」开头的最新记录。展开 Web 步骤看页面截图，展开 API 步骤对照 HTTP 422 和 201 的结果。终端也会打印运行 ID 和报告导出目录。

脚本使用控制台的正常接口创建两条用例、批准、创建计划、执行预检查并运行。每次运行都会在所选后端创建一批可查看的演示记录，并将 HTML、JSON 和 JUnit 报告复制到 `artifacts/equipment-demo/<运行 ID>/`。

源码后端默认使用 `8000` 端口。使用 Windows 安装版时可运行 `python demo/run_flow.py --backend-port 18000 --headed`。若演示端口被占用，启动时指定 `--port 8767`，运行脚本时对应指定 `--demo-port 8767`。

## 要展示的用例

| 用例 | 核对内容 |
| --- | --- |
| [Web 表单](cases/web-request.json) | 超额提交显示数量上限。调整数量后可以提交，回执显示设备名和数量。 |
| [领用 API](cases/api-request.json) | 超额申请返回 HTTP 422 和限额。有效申请返回 HTTP 201 和回执。 |

两条用例都采用结构化动作，可在用例管理和测试计划中查看和复跑。演示数据由示例程序提供，回执仅显示在当前浏览器页面。
